# Geografía · El relieve de España

App de estudio para el examen de Geografía de 2.º de Bachillerato: conceptos del bloque I en tarjetas,
mapa político y físico interactivos, coordenadas, escalas y el comentario del paisaje del Tajogaite.

**Abrir:** https://hamzaleghouiti12-sketch.github.io/geografia/

**Instalar en el móvil**
- iPhone/iPad: abre el enlace en Safari → Compartir → «Añadir a pantalla de inicio».
- Android: en Chrome → menú ⋮ → «Instalar aplicación».

Después funciona sin conexión; el progreso se guarda solo en ese móvil.

Mapas: límites de provincias de [click_that_hood](https://github.com/codeforgermany/click_that_hood) y países de
[world.geo.json](https://github.com/johan/world.geo.json). Foto del Tajogaite: Javier Dóniz, 2022.
